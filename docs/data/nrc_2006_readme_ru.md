# NRC 2006 — расширенная база нормативов для собак и кошек

Файл: `nrc_2006_expanded_ru.json`

**Состояние:** исследовательский перенос (`draft_review_required`), не готов к самостоятельной клинической эксплуатации без независимой вычитки и утверждения ветеринарным диетологом.

## Состав

- 43 нутриента в каталоге (43 различных кода).
- 8 профилей; 5 развёрнутых профилей RA (поддержание взрослых собак/кошек, две фазы роста щенков и рост котят).
- 3 **незавершённых** репродуктивных профиля (выбор в клиническом калькуляторе запрещён).
- 225 записей по нутриентам, включая 12 неполных записей по репродукции.
- Для части записей добавлен MR, если он прямо приведён в соответствующей таблице.
- Все RA указаны **на 1000 ккал обменной энергии**; единицу каждого нутриента необходимо читать из `catalogs.nutrients[].unit_per_1000_kcal_me` и `nutrients[].unit`.

## Важная семантика JSON

`minimum` в каждой записи с `category: "RA"` — **рекомендуемая обеспеченность** NRC, а не физиологический MR. Числовое значение MR, если установлено, записано в `reference_values.MR`. Поле `maximum: null` **не означает отсутствия верхнего токсикологического предела**: SUL не перенесены в текущую редакцию, поскольку требуют отдельной вычитки и проверки единиц измерения.

Некоторые перепечатки таблиц NRC ошибочно трактуют значения в г/кг сухого вещества как г/1000 ккал или неправильно обозначают размерность натрия. Не импортируйте из них колонку «Maximum» автоматически. Для витамина A используются мкг ретинолового эквивалента, **не IU**.

NRC отдельно оговаривает таурин кошек для очищенных, сухих экструдированных и консервированных рационов. RA=0,1 г/1000 ккал нельзя использовать как универсальный стандарт для промышленного влажного и сухого корма: см. `special_rules`.

## Использованные первичные и проверочные источники

1. NRC (2006), *Nutrient Requirements of Dogs and Cats*, DOI: https://doi.org/10.17226/10668
2. Pet Food Institute, петиция USDA (2012), приложение E с воспроизведёнными таблицами NRC 15-3, 15-5, 15-8, 15-10, 15-12, 15-14: https://www.ams.usda.gov/sites/default/files/media/Amino%20Acid%20Pet%20Food%20Petition.pdf
3. Дополнительные текстовые перепечатки таблиц для проверки отдельных строк — ссылки в `source.additional_table_copy_url` у соответствующих профилей; они **не являются заменой оригинальному NRC**.

## Что осталось для продуктивной версии

- Независимая ручная сверка всех 225 строк и сохранение исходных примечаний по каждой таблице.
- Полный перенос таблиц 15-8 и 15-14 (репродукция) с разграничением беременности и лактации.
- Отдельная матрица SUL и проверки взаимодействий нутриентов, видов рационов и биодоступности.
- Проверка соотношений Ca:P и отдельные ограничения для быстрорастущих щенков крупных пород.
- Раздельное хранение NRC 2006 и современных профилей AAFCO/FEDIAF без смешивания нормативов.
